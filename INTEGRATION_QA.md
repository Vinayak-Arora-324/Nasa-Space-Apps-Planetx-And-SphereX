## Bugs found and changes made

| Finding | Resolution / evidence |
|---|---|
| Typed WISE challenge coordinates were treated as a fixed old sky position, with no proper motion. | Fixed. Recognise only coordinates within 1″ of this specific challenge example, resolve its named catalogue astrometry, and propagate to epoch 2026. The note explains the association. Named and typed paths now agree exactly. |
| WISE fallback used an estimated epoch for the older challenge position. | Replaced by the J2000 astrometry returned by the live resolver in this pass, with matching proper motion/epoch. Resolver remains the normal path. |
| Supplying only one proper-motion component silently disabled motion. | Fixed: missing component is zero, consistent with the backend. A real one-axis request agreed with backend target coordinates to 0.000229 pixels. |
| Zoom before any field was loaded threw a null-WCS exception. | Reproduced and fixed with an empty-view guard; rechecked without an exception. |
| Playback could retain old callbacks across reloads, and repeated Play calls could schedule more than one loop. | Fixed by tracking/cancelling the animation-frame handle and halting on abort/reload. Reset controls immediately. Keyboard stepping and playback were exercised; all five targets animated in the final pass. |
| A selected detector with no loaded frames silently displayed a different detector. | Fixed: keep the selected detector and show an empty selection. Tested D1 after loading only D6; selected D1, zero items, clear message. |
| Locked stretch cache keyed image-set identity only by string length, so different detectors could reuse each other's limits. | Fixed: key includes selected detector/list, mode and difference sources. Detector switching and stacks inspected in real data. No isolated numerical regression measurement was made for the old cache bug. |
| Stacks/limits computed during progressive loading could accumulate obsolete cache entries. | Clear derived caches on rebuild while loading. R Dra worked with 800 frames. This was not a full memory-profile or 3,000-frame stress test. |
| A stale catalogue response could populate a newer field. | Guard responses by load generation. Ordinary field changes and overlays passed; the exact race was not artificially forced. |
| After Stop and keep, catalogue requests inherited an already-aborted signal. | Fixed by giving retained-field work a fresh controller. Real post-stop Gaia request passed. |
| Stop and keep immediately triggered full-selection photometry, potentially restarting downloads. | Fixed: automatic photometry is skipped after stop; manual measurement remains available and its full-selection scope is stated. |
| A cleanly closed but truncated binary stream could be treated as a completed load. | Fixed: require end record and complete record bytes. New Node regression test verifies rejection. |
| When every frame failed, the early no-image return could hide failed-frame details. | Fixed and verified by explicit failed-stream injection. |
| Zero frames matching filters looked like a loading failure. | Added a separate detector/date empty-selection message; verified against the real backend. |
| Waiting text promised shorter exposure queries than were observed and named IRSA as the only pixel source. | Reworded for several-minute delays and generic archive cutouts; replaced fabricated query percentage with an indeterminate bar and reduced-motion fallback. |
| Predominantly saturated variable-star charts could imply reliable variability. | Added an explicit majority-flag/saturation warning. Verified with RW Aur on desktop and phone. |
| Empty-coverage text asserted the mission had not covered the whole sky. | Reworded to describe only the archive response. The zero-response path was fault-tested. |
